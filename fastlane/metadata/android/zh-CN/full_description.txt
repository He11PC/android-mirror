Mirror 是一款适用于 Android 的多协议镜像备份应用。
它比同步软件更简洁轻便，允许您使用自己的基础设施，而非第三方云服务。

您可以按如下方式配置多个备份：

* 选择源目录
* 选择目标目录
* 选择过滤选项（可选）
* 配置自动计划任务（可选）

Mirror 将分析源目录和目标目录的内容，进行比较，并根据您选择的过滤选项，将源目录的结构（子目录和文件）复制到目标目录中。

源目录和目标目录可以位于：

* 设备的内部或外部存储
* NFS 共享
* SMB 共享
* FTP 或 FTPS 服务器
* SFTP 服务器
* WebDAV 服务器

**安全与隐私**

* **本地存储：**敏感信息使用 Room 数据库进行加密（AES-GCM + Android KeyStore），并存储在您的设备本地。
* **无追踪：**本应用程序不包含任何分析、追踪器、广告或专有软件开发工具包（SDK）。
* **开源：**Mirror 是一个独立项目。源代码已在 GitHub 上公开，以确保透明度和审计。
