Mirror — це багатопротокольна програма для резервного копіювання типу дзеркала для Android.
Розроблена як простіша та легша, ніж програмне забезпечення для синхронізації, вона дозволяє використовувати власну інфраструктуру, а не сторонні хмарні сервіси.

Ви можете налаштувати кілька резервних копій наступним чином:

- Виберіть вихідний каталог
- Виберіть цільовий каталог
- Виберіть параметри фільтрації (необов'язково)
- Налаштуйте автоматичне планування (необов'язково)

Mirror проаналізує вміст обох каталогів, порівняє їх та відтворить структуру вихідного каталогу (підкаталоги та файли) у цільовому каталозі, дотримуючись вибраних вами параметрів фільтрації.

Джерело та місце призначення можуть знаходитися на:

- Внутрішньому або зовнішньому сховищі вашого пристрою
- Спільному ресурсі NFS
- Спільному ресурсі SMB
- Сервері FTP або FTPS
- Сервері SFTP
- Сервері WebDAV

<b>БЕЗПЕКА ТА КОНФІДЕНЦІЙНІСТЬ</b>

- <b>Локальна пам'ять:</b> Конфіденційна інформація шифрується (AES-GCM + Android KeyStore) та зберігається локально на вашому пристрої за допомогою бази даних Room.
- <b>Без відстеження:</b> Цей застосунок не містить жодної аналітики, трекерів, реклами чи власних комплектів розробки програмного забезпечення (SDK).
- <b>Відкритий код:</b> Mirror — це незалежний проект. Вихідний код доступний на GitHub для прозорості та аудиту.
