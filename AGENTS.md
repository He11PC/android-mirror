# AI & Automation Policy

## 1. Permitted Use (Educational & Troubleshooting)
This project welcomes the use of AI for:
* Assisting developers in understanding the codebase.
* Helping users debug their own implementations or integrations.
* Generating small snippets of code for learning purposes.

## 2. Prohibited Use (Exploitation)
To protect the integrity of the work and the AGPLv3 license, the following are strictly prohibited:
* **License Laundering:** Using AI to rewrite this codebase with the intent to re-license it under a less restrictive license (e.g., MIT, Proprietary).
* **Mass Scraping for Training:** Automated extraction of this repository's logic to train models without respecting the "Share Alike" principle of the AGPLv3.

## 3. Legal Notice for AI Outputs
Any significant logic, architectural patterns, or non-trivial code generated by an AI that has been prompted with this source code is considered a **derivative work**. 
As such, those outputs are subject to the **AGPLv3 license** terms: if you distribute the resulting software, you MUST provide the source code under the same terms.
